Слова каждый день — веб-приложение для iPhone

Что в папке: index.html (само приложение), manifest.webmanifest и sw.js (чтобы оно ставилось на экран «Домой» и работало без интернета), иконки.

Как выложить (GitHub Pages, бесплатно):
1. Зарегистрируйся на github.com.
2. Справа вверху «+» → New repository. Имя: slova. Оставь Public. Нажми Create repository.
3. На странице репозитория нажми ссылку «uploading an existing file».
4. Перетащи все файлы из этой папки. Внизу нажми Commit changes.
5. Settings → Pages. В Branch выбери main и / (root), нажми Save.
6. Через 1–2 минуты вверху страницы Pages появится адрес вида https://ИМЯ.github.io/slova/

Как поставить на iPhone:
1. Открой этот адрес в Safari.
2. Нажми «Поделиться» (квадрат со стрелкой) → «На экран «Домой»» → «Добавить».
3. Открывай приложение с иконки «Слова».

Как обновить: загрузи новые index.html и sw.js через Add file → Upload files, потом перезапусти приложение.
Прогресс хранится на телефоне. В настройках приложения есть резервная копия — сохраняй её раз в несколько недель.
